---
description: How to build the Android APK
---

To build the debug APK for testing:

1. Open the terminal.
2. Navigate to the project root (the folder that contains `gradlew.bat`).
3. Run the Gradle build command:

```powershell
./gradlew.bat assembleDebug
```

4. Once the build completes, the APK will be located at:
   `app/build/outputs/apk/debug/app-debug.apk`

// turbo
5. Run the build command now.
